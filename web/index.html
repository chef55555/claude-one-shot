    ⚙️ How this exists

    • Heartbeat: an hourly schedule: workflow runs the deterministic simulation and commits the new state.
    • Database: none — the world state is JSON in the repo; its full history is the git log.
    • API: none — GitHub Issues are the write path, GitHub Pages is the read path.
    • Seed: a hash. Same seed, same universe, forever replayable.
